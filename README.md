# NeuronCopilot: Agentic Learning System

An AI tutor combining RAG, Neo4j knowledge graphs, 
and adaptive teaching behaviors for personalized learning.

## Features
 -4 teaching behaviors (Socratic, quiz, clarification, code)
 - Neo4j knowledge graph for prerequisites 
-Local deployment (Ollama, LlamaIndex, Streamlit) 
-Student personalization 

## Quick Start 
```bash 
cd Neuron_Copilot_Demo 
streamlit run app.py 
```
Login: `student_001` 

## Architecture

-**RAG:** LlamaIndex + course materials
-**Graph:** Neo4j concept dependencies
-**Teaching:** 4 adaptive behaviors
-**UI:** Streamlit web interface
## AWS Deployment
EC2 + RDS + S3 ready
